My events table has a meta jsonb column. Queries like meta->'tags' ? 'billing' are slow at 40M rows. What index should I add?

Kestrel 3 Pro 2.1s

Use a GIN index on just the tags path with jsonb_path_ops. It's smaller and faster for containment checks than indexing the whole document:

sqlCopy
CREATE INDEX CONCURRENTLY events_meta_tags_gin
  ON events USING gin ((meta->'tags') jsonb_path_ops);

-- then rewrite the predicate as containment:
SELECT id FROM events
 WHERE meta->'tags' @> '["billing"]' LIMIT 50;
  • jsonb_path_ops supports @> but not ?, so switch the operator.
  • CONCURRENTLY avoids locking writes while it builds.
