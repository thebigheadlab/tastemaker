# Bundled card fonts

These unmodified Latin WOFF2 assets preserve the condensed and dotted lettering in the Nike and Nothing cards. The build embeds the font data and licenses in each affected card, so the exported page works offline.

| --- | --- | --- | --- |
| Anton | Anton-latin.woff2 | [Google Fonts asset](https://fonts.gstatic.com/s/anton/v27/1Ptgg87LROyAm3Kz-C8.woff2) | [Anton-OFL.txt](Anton-OFL.txt) |
| Doto | Doto-latin.woff2 | [Google Fonts asset](https://fonts.gstatic.com/s/doto/v3/t5t6IRMbNJ6TQG7Il_EKPqP9zTnvqouBWho.woff2) | [Doto-OFL.txt](Doto-OFL.txt) |

The application code retains its MIT license. The font files remain under SIL OFL 1.1.
